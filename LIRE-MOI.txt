P'TIT BAC — CORRECTIF CORE V1

Ce ZIP corrige la première grosse couche du diagnostic sans toucher au design.

POURQUOI UN PATCH AUTOMATIQUE ?
Le connecteur GitHub disponible dans cette conversation a l'accès en lecture,
mais GitHub a refusé l'écriture avec l'erreur 403 "Resource not accessible by integration".
Le script évite donc de réécrire manuellement les ~130 Ko de server.js.

FICHIERS FINALEMENT MODIFIÉS
- server.js
- frame-sync-server.js
- package.json

CORRECTIONS
- Suppression du monkey-patch Module._extensions.
- Suppression des monkey-patches Server.prototype.on / Server.prototype.to.
- Les règles ne sont plus modifiées au chargement de Node.
- Coût relance lettre = 20 pièces directement dans server.js.
- Coût relance catégories = 20 pièces directement dans server.js.
- Relances rapides toujours autorisées.
- Difficulté rapide = medium directement dans server.js.
- frameId stocké dans le joueur et envoyé dans room:state.
- cosmetics:sync contrôlé via requireMember.
- Reconnexion resynchronise le cadre.
- Suppression de la route /health dupliquée.
- npm start = node server.js.
- npm run dev = node --watch server.js.
- Les tests quick-match restent actifs.

UTILISATION
1. Mets apply-core-cleanup.cjs à la racine de P'tit-bac
   (au même niveau que server.js et package.json).
2. Dans un terminal ouvert dans ce dossier:
      node apply-core-cleanup.cjs
3. Le script lance automatiquement:
      node --check server.js
      node --check frame-sync-server.js
      node --check quick-match.js
      node --test quick-match.test.cjs
4. S'il y a la moindre erreur, les trois fichiers sont restaurés automatiquement.
5. Si tout est vert, supprime apply-core-cleanup.cjs et envoie uniquement:
      server.js
      frame-sync-server.js
      package.json
   sur GitHub.

IMPORTANT
Le script reconnaît la structure de la version auditée du dépôt Winstudi/Ptit-bac.
Si server.js a été modifié entre-temps et que les motifs ne correspondent plus,
le patch s'arrête au lieu de forcer la modification.
