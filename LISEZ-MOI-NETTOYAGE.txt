1. Décompresser le ZIP.
2. Copier son contenu à la racine du dépôt GitHub en remplaçant les fichiers
   de même nom. Conserver le dossier .github et son sous-dossier workflows.
3. Conserver tous les autres fichiers du dépôt. Ne pas déposer le ZIP lui-même
   comme remplacement du code.
4. Aucun script de correction n’est à exécuter. Ne pas lancer les anciens
   apply-stabilisation-1.49*.cjs après ce correctif.

CONFIGURATION / RENDER
Le propriétaire administrateur déjà enregistré est conservé.
Pour attribuer explicitement un propriétaire sur une nouvelle base, utiliser
PTITBAC_ADMIN_USER_ID avec l’UUID d’un utilisateur existant (public.users.id).
Les connexions PostgreSQL distantes vérifient désormais le certificat TLS.
Si nécessaire, fournir le certificat de l’autorité privée via PTITBAC_DB_CA.
Si Render utilise une commande de build définie manuellement, l’aligner sur
render.yaml :
npm ci --include=dev && npm test && npm run check && node cleanup-frontend-build.cjs && npm run check:production && (node optimize-assets.cjs || echo "Optimisation WebP ignorée - fallback PNG actif")
